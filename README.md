# Vanilla JavaScript Calculator

A clean, lightweight, and responsive calculator built from scratch using only vanilla HTML, CSS, and JavaScript. 

## ✨ Features
- Performs basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Clear and reset functionality
- Responsive design that works on mobile and desktop

## 🏗️ Clean Architecture
This project prioritizes foundational web standards:
- **Semantic HTML:** Uses proper structural tags for better accessibility and readability.
- **Vanilla CSS:** Styled without any frameworks to demonstrate core CSS skills.
- **Clean JavaScript:** Written in modern ES6+ without external libraries.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
